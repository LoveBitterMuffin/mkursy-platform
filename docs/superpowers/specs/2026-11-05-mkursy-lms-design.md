# Спецификация дизайна: Образовательная платформа «МКурсы» (Next-Gen Math LMS)

**Дата:** 2026-11-05  
**Статус:** Согласовано с пользователем  
**Проект:** «МКурсы» — Центр дополнительного образования по математике (5–11 классы)

---

## 1. Контекст и цели проекта

### 1.1. Проблема традиционных LMS (Moodle)
Moodle создавался более 20 лет назад как тяжеловесный PHP-монолит с серверным рендерингом (SSR). Для преподавания математики школьникам 5–11 классов Moodle обладает критическими недостатками:
1. **Сложность создания контента:** перегруженные формы из 40+ настроек на один вопрос, отсутствие блочного визуального редактора.
2. **Слабая поддержка математики:** тяжелый и архаичный ввод формул LaTeX, отсутствие встроенных интерактивных графиков и динамических геометрических моделей.
3. **Отталкивающий интерфейс для школьников:** отсутствие геймификации, наглядных деревьев навыков и современного мобильного опыта (Mobile-first).

### 1.2. Миссия «МКурсы»
Создать специализированную, сверхбыструю, визуально привлекательную образовательную платформу для центра математики «МКурсы», сочетающую:
* **Конструктор интерактивных математических уроков** (Split-View с живым предпросмотром);
* **Интерактивную карту знаний (RPG Skill-Tree)** со светящимися созвездиями тем;
* **Личный кабинет школьника** с трекингом стриков активности, опыта (XP) и прогнозом баллов ОГЭ/ЕГЭ.

## 2. Архитектура и стек технологий

### 2.1. Технологический стек
* **Frontend:** React 18/19, TypeScript, Vite, Tailwind CSS.
* **Математика и визуализации:**
  * `KaTeX` — быстрый рендеринг математических формул $\LaTeX$.
  * Интерактивный координатный холст (Canvas / SVG) с ползунками динамических параметров функций ($f(x) = kx + b$, параболы, тригонометрия).
  * `Lucide React` — чистый современный набор иконок.
* **Брендинг «МКурсы»:**
  * Использование имеющихся активов бренда: `Logo big M.png`, `Logo mini (????).png`.
  * Цветовая палитра: глубокий индиго/нави (основа `#0B132B`, `#1C2541`), электрик/фиолетовый акцент (`#6366F1`, `#8B5CF6`), изумрудный (`#10B981` — освоено), янтарный (`#F59E0B` — в процессе), рубиновый (`#EF4444` — ловушки/ошибки).

## 3. Функциональные модули MVP

### 3.1. Конструктор уроков (Split-View Workspace)
* **Левая панель (Редактор блоков):**
  * Добавление блоков: Текст/Теорема, Формула LaTeX, Интерактивный график, Видеоразбор, Квиз.
  * Палитра быстрых математических символов: вставка дробей $\frac{a}{b}$, корней $\sqrt{x}$, степеней, систем уравнений без ручного набора LaTeX.
  * Настройка функции графика и диапазона параметров (ползунки $a, b, c$).
  * Настройка вопросов квиза: варианты, математический ввод, ступенчатые подсказки и подробный разбор решения.
* **Правая панель (Live Student Preview):**
  * Интерактивный предпросмотр урока в реальном времени.
  * Переключение режима просмотра: «Десктоп» / «Смартфон».
  * Интерактивная работа ползунков графика и проверка ответов прямо в превью.

### 3.2. Интерактивная карта знаний (RPG Skill-Tree)
* **Граф созвездий тем:**
  * Темы-узлы математики (Алгебра, Геометрия, Уравнения, Функции, Тригонометрия, ОГЭ/ЕГЭ профиль).
  * Связи между темами (Prerequisites): открытие сложных тем только после закрытия базы.
  * Свободное панорамирование (Drag & Pan) и плавный зум.
  * Статусы узлов:
    * 🔒 *Заблокировано* (база не освоена);
    * 🟡 *В процессе* (урок начат);
    * 🟢 *Освоено* (тест сдан на 80%+);
    * 💎 *Мастерство* (решены сложные олимпиадные/ЕГЭ задачи).
  * Информационная карточка по клику на узел с кнопкой «Перейти к уроку».

### 3.3. Личный кабинет ученика и статистика
* **Виджет прогресса:** дни активности (Стрик 🔥), набранный опыт (XP), процент готовности к экзамену.
* **Прогноз баллов ОГЭ / ЕГЭ:** динамический расчет прогнозируемого тестового балла на основе закрытых узлов дерева.
* **Сводка для родителей:** прозрачный блок успеваемости (сданные задания, активность за неделю).

## 4. Спецификация моделей данных (TypeScript)

```typescript
export type SkillCategory = 'algebra' | 'geometry' | 'probability' | 'calculus' | 'olympiad';
export type SkillStatus = 'locked' | 'available' | 'in_progress' | 'mastered';

export interface SkillNode {
  id: string;
  title: string;
  category: SkillCategory;
  grade: number; // 5..11
  x: number; // Координаты на холсте
  y: number;
  prerequisites: string[]; // ID родительских тем
  status: SkillStatus;
  progress: number; // 0..100
  xpReward: number;
  lessonId: string;
}

export type LessonBlock =
  | {
      id: string;
      type: 'text';
      content: string;
      calloutType?: 'info' | 'theorem' | 'trap' | 'property';
    }
  | {
      id: string;
      type: 'math';
      latex: string;
      caption?: string;
      explanation?: string;
    }
  | {
      id: string;
      type: 'plot';
      title: string;
      fnExpression: string; // e.g. "a * x^2 + b * x + c"
      params: Array<{
        name: string;
        label: string;
        min: number;
        max: number;
        step: number;
        value: number;
      }>;
    }
  | {
      id: string;
      type: 'video';
      title: string;
      url: string;
      durationMinutes: number;
    }
  | {
      id: string;
      type: 'quiz';
      question: string;
      options: string[];
      correctOptionIndex: number;
      mathAnswer?: string;
      hints: string[];
      explanation: string;
    };

export interface Lesson {
  id: string;
  skillId: string;
  title: string;
  description: string;
  estimatedMinutes: number;
  blocks: LessonBlock[];
}

export interface StudentProfile {
  name: string;
  grade: number;
  targetExam: 'oge' | 'ege_profile' | 'olympiad';
  streakDays: number;
  totalXp: number;
  forecastScore: number;
}
```

## 5. Границы MVP и фазы развития

### Входит в MVP (Фаза 1):
1. Интерактивная карта знаний (RPG Skill-Tree) с навигацией и фильтрами по разделам математики.
2. Конструктор уроков (Split-View) с интерактивным графиком функций, KaTeX формулами и квизом.
3. Плеер уроков для ученика с пошаговым прохождением и анимациями начисления XP.
4. Дашборд ученика со стриками и прогнозом баллов ОГЭ/ЕГЭ.
5. Фирменный стиль и брендинг центра «МКурсы».

### Фаза 2 (Будущее расширение):
* Модуль проверки рукописных ДЗ с аннотациями поверх фото тетрадей.
* Telegram-бот для учеников и родителей.
* Бэкенд с базой данных PostgreSQL и многопользовательской авторизацией.
