# МКурсы — Платформа математического образования

Современная интерактивная образовательная веб-платформа для подготовки к экзаменам (ОГЭ/ЕГЭ), олимпиадам и изучения школьного курса математики. Платформа построена на компонентной архитектуре с древом навыков, ролевой моделью пользователей, встроенной CRM, видеоуроками и системой приёма домашних заданий.

---

## Ключевые возможности

- **Интерактивное древо навыков (Skill Tree):** наглядная карта математических тем с зависимостями, узлами прогресса и мгновенным переходом к обучению.
- **5 ролевых режимов:**
  - 🎓 **Ученик:** дашборд прогресса, плеер уроков, квизы, сдача домашних заданий с прикреплением фото, каталог курсов.
  - 👨‍🏫 **Учитель:** публикация видеоуроков, очередь проверки решений, выставление оценок и обратной связи.
  - 👨‍👩‍👧 **Родитель:** подробный отчёт об успеваемости ребёнка, статистика занятий и статус оплаты.
  - 🧭 **Куратор:** распределение учащихся по мини-группам (до 10 человек), отслеживание динамики групп.
  - ⚙️ **Администратор:** управление CRM, статусы оплат, карточки клиентов, экспорт данных.
- **Интерактивный плеер уроков:** поддержка формул KaTeX, видео, пошаговых квизов, валидации математических ответов.
- **Оплата и мини-группы:** каталог курсов, адаптер оплаты (карты, СБП, промокоды), автоматическое зачисление в группы до 10 человек.
- **Панель разработчика (DevTools):** быстрое переключение ролей в 1 клик, симулятор вебхуков платёжной системы (`payment.succeeded`, `payment.failed`), сброс демо-данных.
- **Темизация:** полноценная поддержка светлой и тёмной темы.

## Стек технологий

- **Фреймворк:** React 18 + TypeScript + Vite
- **Стилизация:** Tailwind CSS + PostCSS + Onest Font
- **Формулы и графика:** KaTeX + Lucide React
- **Тестирование:** Vitest + React Testing Library + JSDOM (114 автоматических тестов)

## Быстрый запуск с нуля (Автоматический режим)

В репозиторий встроены скрипты самодиагностики. Они проверяют версию Node.js, npm, наличие зависимостей, при необходимости автоматически запускают `npm install` и поднимают сервер.

### Вариант 1: Windows (1 клик)
Просто дважды кликните по файлу **`start.bat`** в проводнике.

### Вариант 2: PowerShell (Windows)
Откройте терминал PowerShell в папке проекта и выполните:
```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

### Вариант 3: Кроссплатформенный запуск (macOS / Linux / Windows)
Выполните команду через npm или напрямую через Node.js:
```bash
npm start
# или
node start.mjs
```

Сервер разработки будет доступен по адресу: **`http://localhost:5173`**

## Ручной пошаговый запуск (Manual Setup)

Если вы хотите выполнить все шаги вручную:

### 1. Системные требования
- **Node.js:** версия `18.0.0` или новее ([скачать с официального сайта](https://nodejs.org/))
- **npm:** версия `9.0.0` или новее (устанавливается вместе с Node.js)
- **Git:** для клонирования репозитория

### 2. Клонирование репозитория
```bash
git clone https://github.com/LoveBitterMuffin/mkursy-platform.git
cd mkursy-platform
```

### 3. Установка зависимостей
```bash
npm install
```

### 4. Запуск в режиме разработки
```bash
npm run dev
```
После запуска откройте браузер по адресу: `http://localhost:5173`.

## Устранение неполадок (FAQ)

### 1. Ошибка запуска PowerShell (`Execution_Policies`)
Если при запуске `start.ps1` система сообщает о запрете выполнения скриптов:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\start.ps1
```
Либо используйте готовый файл `start.bat` или команду `npm start`.

### 2. Порт 5173 уже занят
Если порт 5173 занят другим процессом, сборщик Vite автоматически выберет следующий доступный порт (например, `5174`), о чём сообщит в консоли.

### 3. Ошибки после изменения версий пакетов
Для чистой переустановки зависимостей:
```bash
# Windows PowerShell:
Remove-Item -Recurse -Force node_modules, package-lock.json; npm install

# Linux / macOS:
rm -rf node_modules package-lock.json && npm install
```
